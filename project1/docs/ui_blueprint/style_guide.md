Nama aplikasi:
SIRUANG (Sistem Informasi Ruangan)

Tema visual:
Modern, Clean, & Academic Identity (Berbasis Identitas Visual Unmuh Jember)

Warna utama:
Navy / Biru Gelap (#253C6D / #1D3557)

Alasan memilih warna utama:
Memberikan kesan profesional, resmi, stabil, dan tepercaya sesuai dengan identitas warna utama kampus Universitas Muhammadiyah Jember, sekaligus menjaga kenyamanan visual pengguna saat memantau data perkuliahan.

Warna pendukung:
Oranye / Amber (#E89951 / #E99649)

Warna latar:
Putih (#FFFFFF) & Abu-abu Terang (#F2F2F2 / #F5F5F5)

Warna teks:
Teks Utama (Judul/Kode Ruang): Hitam Pekat / Gelap (#1A1A1A / #222222)
Teks Subjudul & Muted: Abu-abu Gelap (#666666)
Teks Kontras tinggi: Putih (#FFFFFF) untuk latar Navy/Oranye

Judul:
Poppins / Inter, Bold, ukuran 16px – 18px

Subjudul:
Poppins / Inter, Semi-Bold / Medium, ukuran 12px – 14px

Isi teks:
Poppins / Inter, Regular, ukuran 10px – 12px

Tombol utama:
Rounded Button (Radius 10px), latar warna Oranye (#E89951), teks Putih (#FFFFFF), full-width

Tombol sekunder:
Rounded Button (Radius 10px), latar warna Oranye Transparan / Outline, teks Oranye

Pola kartu/komponen:
Card UI dengan sudut tumpul (Border Radius 10px), latar abu-abu terang (#F2F2F2), padding internal yang teratur untuk pemisahan informasi statistik dan jadwal perkuliahan.

Catatan accessibility warna/teks/touch target:
Kontras: Teks putih di atas latar Navy (#253C6D) dan teks gelap di atas latar abu-abu terang memenuhi rasio kontras keterbacaan WCAG.
Touch Target: Seluruh tombol utama dan filter dibuat presisi dengan area sentuh nyaman untuk jempol (thumb zone) di bagian bawah layar.
Tipografi: Menggunakan jenis font Poppins dengan ketebalan terstruktur agar hierarki informasi mudah dibaca pada berbagai ukuran layar smartphone.
